Portfolio Website
My personal portfolio built with React + Vite, styled using Tailwind CSS, enhanced with Lucide icons, and featuring a contact form powered by EmailJS.


# ✨ Features
- ⚡ Fast build setup with Vite
- 🎨 Responsive UI styled with Tailwind CSS
- 📬 Contact form integrated with EmailJS (sends messages directly to my inbox)
- 🔗 Reusable components with React
- 🖼️ Clean icons via Lucide
